One task. One worktree. No shared state.

Agentree runs independent coding tasks in isolated Git worktrees. Each task gets its own branch, index, checks, and explicit path back to main.

A small, explicit workflow.

Agentree keeps Git visible. It adds boundaries and records around the parts that are easy to get wrong.

  1. 1

    Create

    Start a task from an exact commit in its own branch, worktree, and index.

  2. 2

    Check

    Run configured checks and record the exact task revision that passed.

  3. 3

    Land

    Sync deliberately, then fast-forward the target when the task is ready.

Dirty worktrees stay untouched. Risky Git operations stay blocked. Interrupted work stays inspectable.

Start with one task.

Install from crates.io, then initialize an existing Git repository.

Read the quick start 
$ cargo install agentree --locked
$ cd path/to/repository
$ agentree init
$ agentree new parser-error --base main
