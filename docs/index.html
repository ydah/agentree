A deliberate path from task to trunk.

Work never drifts into the target branch by accident. Each transition is explicit, reviewable, and tied to an exact revision.

01

Create

Start from an exact base commit with a dedicated branch, worktree, and Git index.

02

Run and check

Supervise commands locally and record checks against the task’s exact HEAD.

03

Sync

Rebase onto a chosen target commit and resolve conflicts deliberately.

04

Land

Fast-forward the target only when the task state and revision are ready.

Safety lives in the workflow.

Agentree makes risky shortcuts difficult and recovery information durable, without hiding Git behind a new mental model.

Isolation that is real

Each task owns its working directory and index. Parallel agents do not share mutable worktree state.

Checks with provenance

Required commands, configuration, and revision are recorded together, so “passed” keeps its meaning.

No surprise landing

Sync and land stay separate. Integration is an explainable fast-forward, never a silent rebase.

Recovery leaves a trail

Journals, checkpoints, and plan-first diagnostics keep interrupted operations inspectable.

Start with one task.

Install from crates.io, initialize an existing Git repository, and give the next change its own worktree.

Open full documentation 
$ cargo install agentree --locked
$ cd path/to/repository
$ agentree init
$ agentree new parser-error --base main
$ agentree run parser-error -- cargo test
$ agentree check parser-error
✓ task/parser-error is ready to land
